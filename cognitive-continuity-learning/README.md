# 认知连续学习 Skill｜使用说明

## 核心定位
一套同时面向知识点、数学公式、算法、教材、科研论文的中文教学指令。不是固定教材，也不是自动出题系统。核心是「真实问题—旧办法—新需求—具体操作—新结果」的一条可跟随的认知主线。

## 文件
- `SKILL.md`：主技能，包含启动条件、十项已确认原则、数值与公式教学、算法「小数据+真实研究」、论文证据、卡点修补、互动收尾和完整质量检查。**单用这个文件即可**。
- `references/acceptance-tests.md`：后续对比、测试、修订时可用的场景与检查标准，不是必须同时加载的教学材料。

## 最简使用
- “按认知连续学习法解释条件期望。”
- “按认知连续学习法学习 DPLS，先用小数据演示核心机制，再解释论文中如何评价。”
- “按认知连续学习法精读《从关联到可预测性与因果性》。”
- “我不理解刚才的关系，按这个 Skill 最小修补。”
- “继续。”
- “检验我是否真的理解，按这个 Skill 一次问一道题。”

## 安装与调用说明
此处提供的是可复用的 Skill 文件及其 ZIP 打包，**不表示已自动安装**到 ChatGPT、Codex、桌面端或其他平台。具备自定义 Skill 功能的平台，可按该平台官方方式导入 `SKILL.md` 或整个文件夹；不具备原生技能机制时，可将 `SKILL.md` 正文作为新对话首条指令，再附上论文与当前问题。跨会话的主线状态应随对话内容或进度笔记一起提供，不能仅靠技能文件保证记住学习进度。
