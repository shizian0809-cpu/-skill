# 论文故事解读

> 跟住对象、行动与证据，读懂一篇研究为什么这样展开。

**从研究问题走到有证据支持的结论。** 这个 Skill 先核对论文材料，再把原问题、旧办法的困难、新方法、关键实验与结果、现实验证和实质局限串成连续研究故事。

## 核心能力

- **先建立研究轮廓**：提炼少量关键词，写清它们之间的动作或关系，以及证据在哪里。
- **让行动有动机**：每一步实验或比较，都接住已经出现的问题、歧义或应用需要。
- **打开方法过程**：展示数据形态、必要操作和输出，解释结果怎样回答研究问题。
- **带着问题读图**：说明坐标、单位、图例、关键对比和证据边界，检查不同子图的尺度。
- **用关键配图帮助理解**：优先论文原图、真实对象与可靠示意，裁图保留刻度、图例和来源。
- **让叙事服从事实**：区分原文事实、计算结果、教学例子、合理情境重建和待验证推测。
- **保持阅读连续**：记录已完成关系、待完成关系、稳定例子与停点，续讲不反复开头。
- **把局限放回判断位置**：区分关联与因果、候选位置与功能验证、速度与准确性等。

## 支持哪些阅读方式

| 你的要求 | 默认处理 |
|---|---|
| 一口气讲完整篇 | 在可得完整原文的基础上闭合主要研究链，覆盖关键方法、实验、结果和局限 |
| 分段讲 | 每轮完成一个自然的研究片段，到合适停点结束 |
| 继续 | 从未完成的关系接着讲，保持对象和例子连续 |
| 解释某个词、某句话、某张图 | 先解决局部困难，避免重新讲整篇 |
| 文字不变，只增图 | 以指定版本为准，在对应位置加入图片 |
| 先停下 | 尊重停止要求，保留已有进度 |

实际材料或输出能力不足时，应明确已覆盖范围，不能把摘要解读说成全文精读。

## 调用示例

~~~text
$lunwen-gushi-jiangjie 解读我附上的论文。先给核心关键词之间的关系，再分段讲清研究故事。

$lunwen-gushi-jiangjie 一次讲完整篇，覆盖方法、关键实验、真实数据验证和局限，结合原图解释结果。

$lunwen-gushi-jiangjie 只解释图 3：作者为什么做这个比较？从一个具体样本带我读坐标和结果。

继续。沿用刚才的数据和术语，从上次尚未解决的问题往前讲。
~~~

可提供论文 PDF、正文、图片或可访问链接；完整阅读最好提供完整论文及必要补充材料。

## 图片、来源与环境条件

图片是否能读取和显示，取决于当前助手的实际工具。原 Skill 包含 DeepSeek Harness 中的 `pdf-toolkit`、`read_image`、`present` 等适配说明；其他平台需提供等效能力。

有图像工具时先读取核对，再展示对应原图；无法展示时应说明真实限制，保留图号、页码、来源和看图说明。故事里的情境重建可以帮助连接逻辑，不能据此声称真实作者有过某段经历。
