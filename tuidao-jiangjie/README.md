# 推导讲解

> 从你已经理解的地方出发，走到一个概念自然出现的位置。

**适合“定义读懂了字面，却不知道为什么要这样定义”的学习困难。** 本 Skill 根据理解依赖组织知识，让每一步都接住前一步留下的问题，最后再把目标概念拼装成完整定义。

## 能带来什么

| 能力 | 讲解时的具体做法 |
|---|---|
| 找到合适起点 | 默认以初中刚毕业的基础出发，也可按你明确说明的水平调整 |
| 按依赖逐步引入 | 先建立必要对象与关系，再使用目标术语 |
| 补足隐含结构 | 主动交代“在哪里”“由什么组成”“与相近概念怎样区分” |
| 建立心理图像 | 使用熟悉的类比和简单文字图，并解释与真实对象的对应关系 |
| 从直觉升级到定义 | 先建立够用且正确的理解，随着前置知识到位补充严格表述 |
| 形成可重走的知识链 | 结尾重新连接关键环节，并给出三种版本的目标定义 |

## 用“等位基因”看它怎样工作

可以从“同一种生物的不同个体为什么有差异”进入，逐步连接：

~~~text
可观察的性状差异
→ 遗传信息与基因
→ DNA 与染色体
→ 来自父母双方的遗传信息
→ 同源染色体
→ 基因的位置：基因座
→ 相应位置上同一基因的不同形式
→ 等位基因
~~~

具体顺序按当前学习者最自然的理解路径调整。到目标概念时，再给出：

- **白话版**：用已经理解的普通语言说明。
- **标准版**：给出准确、规范的学科定义。
- **脑内图像版**：用一句容易形成内部图像的话固定关键关系。

上面的链条是教学组织示例，正式定义和适用对象仍需准确说明。

~~~text
$tuidao-jiangjie 从零讲等位基因，每个新术语第一次出现时解释。

$tuidao-jiangjie 讲导数。先从我会算平均变化率的基础出发，最后给正式定义。

$tuidao-jiangjie 我知道概率和比例，但不懂熵。沿着一个连续例子推导，关键关系画出来。
~~~

也可以直接说：“用推导讲解讲 X”“推导讲解：X”“给我推导一下 X”。已经说明在学习概念的上下文中，直接给出概念名也可使用。

## 适合搭配

需要每一步都有数字或操作时，配合[例子驱动讲解](../lizi-qudong-jiangjie/)；长期学习需要稳定情境、主线停点和局部修补时，选[认知连续学习](../cognitive-continuity-learning/)；读论文时可用于补足一个关键前置概念，然后接回[论文故事](../lunwen-gushi-jiangjie/)。
