# 例子驱动讲解

> 每个陌生概念后面，都有一个可以跟着观察的“比如”。

**适合这样的时刻：术语解释了很多，仍然不知道它实际怎样工作。** 这个 Skill 把具体对象和操作放在讲解中心，让数字、代码、画面与结果承担主要解释任务。

## 能做什么

- **概念可观察**：陌生术语出现后，立刻给一个简单、贴合当前问题的例子。
- **公式可计算**：展示公式，再用小数字逐项代入，交代计算结果的含义。
- **算法可跟随**：给出输入，展示关键处理，再摆出输出。
- **新办法有来由**：通过实际对比，指出直观旧办法卡在哪里，新方法改变哪一步。
- **过渡接得上**：保持具体对象清楚，避免连续用抽象名词或含糊代词带过关系。
- **简化有边界**：区分教学假设和原始研究事实，必要时补充限制。

## 一个小体验

讲“感染率”时，可以先给一张划成 100 格的叶片示意，其中病斑占 15 格：

~~~text
感染率 = 病斑面积 / 叶片面积 × 100%
       = 15 / 100 × 100%
       = 15%
~~~

先看见分子、分母和运算，再把关系压缩成定义。接下来若要识别病斑，就继续用具体像素演示颜色判断在哪些情况下有效、在哪些情况下会误判。

这是一段教学示意，实际测量方法与分母范围仍需根据材料确定。

## 可以怎样用

~~~text
$lizi-qudong-jiangjie 解释 for 循环。把每轮变量的值和实际输出摆出来。

$lizi-qudong-jiangjie 用 3 个数据讲方差，展示减平均、平方、求平均的过程。

$lizi-qudong-jiangjie 我没听懂论文里的阈值处理。沿用原来的像素例子，演示输入、处理和结果。
~~~

自然语言也可以：“用例子讲”“代入数字算一遍”“讲具体点”“刚才太抽象了”。
